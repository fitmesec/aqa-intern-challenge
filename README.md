# AQA Intern Challenge

Автоматизированные UI-тесты виджета поддержки на сайте Uchi.ru.

## Технологии

- TypeScript
- Playwright
- Node.js

## Структура проекта

```text
tests/
├── widget.page.ts  # Page Object для взаимодействия с виджетом
└── widget.spec.ts  # Набор автотестов
```

## Установка зависимостей

```bash
npm install
```

## Установка браузеров Playwright

```bash
npx playwright install
```

## Запуск тестов

```bash
npx playwright test
```

## Запуск тестов с открытым браузером

```bash
npx playwright test --headed
```

## Просмотр HTML-отчёта

После запуска тестов:

```bash
npx playwright show-report
```

## Проверяемые сценарии

1. Виджет поддержки открывается.
2. После открытия виджета отображаются популярные статьи.
3. После перехода из популярной статьи к форме обратной связи отображается заголовок «Связь с поддержкой».

## Особенности реализации

- Использован паттерн Page Object Model.
- Для поиска элементов используются устойчивые `data-test`-селекторы.
- Учтено асинхронное появление списка популярных статей.
- Дополнительно реализован тест отображения популярных статей.
